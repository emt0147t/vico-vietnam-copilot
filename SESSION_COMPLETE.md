## 🏛️ Architecture

### System Flow
```
Browser (React)
    ↓ User Input (company name)
    ↓
GTMStrategyPanel
    ├─ Search validation
    ├─ Autocomplete API call
    └─ Strategy generation request
    ↓
Next.js API Layer (/api/gtm/generate)
    ├─ Validate input
    ├─ Query COMPANIES array
    ├─ Search NewsDB
    ├─ Extract signals (17 types)
    ├─ Find competitors
    └─ Call Gemini AI
    ↓
gtmStrategyService
    ├─ generateGTMRecommendation()
    ├─ Build SWOT analysis
    ├─ Calculate feasibility
    └─ Format response
    ↓
Gemini AI API
    ├─ Receive company context
    └─ Generate strategic recommendations
    ↓
Response to Frontend
    ├─ GTMRecommendation object
    └─ Analysis metadata
    ↓
GTMStrategyViewer
    ├─ Tab 1: Overview (strategy + feasibility)
    ├─ Tab 2: SWOT (detailed analysis)
    ├─ Tab 3: Plan (marketing/sales/partner)
    └─ Tab 4: Timeline (3 phases with budgets)
```
