# 📰 News Intelligence Implementation Guide

## Overview
This upgrade adds four powerful features to VICO:

1. **Market Pulse** - News classified into market signals (Funding, M&A, Product Launch, etc.)
2. **AI Summarization** - 3-bullet point summaries generated by Gemini
3. **Sentiment Analysis** - Positive/Negative/Neutral classification
4. **Smart Entity Linking** - Automatic company mention detection and linking

---

## Files Created/Modified

### 1. Core Data Models
- `data/newsModels.ts` - TypeScript interfaces for all news features
  - SignalType enum (9 signal types)
  - SentimentType enum (Positive/Negative/Neutral)
  - NewsItem interface with enriched metadata
  - Keywords for classification

### 2. Data Loading
- `utils/newsLoader.ts` - CSV parser for news import
  - Efficiently loads `d:\Tong_Hop_Tin_Tuc_Final.csv`
  - Handles 38,964 articles with streaming
  - CSV parsing with proper quote handling

### 3. AI Enrichment
- `services/newsEnrichmentService.ts` - Main enrichment pipeline
  - `classifySignals()` - Keyword + Gemini-based signal detection
  - `analyzeSentiment()` - Sentiment classification
  - `summarize()` - 3-bullet AI summaries via Gemini
  - `extractCompanyMentions()` - Entity linking to companies
  - `enrichNewsBatch()` - Parallel enrichment (3 concurrent)

### 4. Database
- `utils/newsDatabase.ts` - MongoDB integration
  - Collection management and indexing
  - Vector search support (for semantic similarity)
  - Bulk import operations
  - Signal/sentiment statistics

### 5. API Routes
- `app/api/news/search/route.ts` - Search by company/signal/sentiment/embedding
- `app/api/news/import/route.ts` - Batch import and enrichment
- `app/api/news/stats/route.ts` - Get market statistics

### 6. Scripts
- `scripts/importNews.ts` - CLI tool for initial import
  - Optional: Add embeddings for vector search
  - Progress tracking
  - Statistics output

### 7. UI Components
- `components/MarketPulse.tsx` - Main news feed with signals
- `components/NewsStatsDashboard.tsx` - Market overview charts (Recharts)
- `components/CompanyNewsSection.tsx` - Integrated into company profiles

## Installation & Setup

### Step 1: Install Dependencies
```bash
npm install recharts
# Already have: @google/genai, mongodb
```

### Step 2: Environment Variables
Add to `.env`:
```env
API_KEY=your_gemini_api_key
MONGODB_URI=mongodb://localhost:27017
```

Ensure MongoDB is running:
```bash
# Windows
mongod

# Or use MongoDB Atlas (cloud)
MONGODB_URI=mongodb+srv://user:pass@cluster.mongodb.net/
```

### Step 3: Import News Data
```bash
# Import all articles (~39K)
npx tsx scripts/importNews.ts

# Import first 5000 articles
npx tsx scripts/importNews.ts 5000

# Import with embeddings (slower, 5-10 min for 5000)
npx tsx scripts/importNews.ts 5000 0 true
```

Monitor progress - script outputs:

✅ Enrichment complete

## Optimization Tips

### 1. Batch Enrichment
```typescript
// Fast: Process 3 articles in parallel
enrichNewsBatch(newsItems, companies, 3)

// Slower: Process 1 at a time
enrichNewsBatch(newsItems, companies, 1)

// Very slow: All at once (rate limit)
enrichNewsBatch(newsItems, companies, 20)
```

### 2. Caching
- API responses cached 5 minutes
- Use `GET /api/news/stats` frequently (cheap)
- Cache signal classification results

### 3. Incremental Import
```bash
# Import in chunks to avoid timeout
npx tsx scripts/importNews.ts 5000 0     # First 5000
npx tsx scripts/importNews.ts 5000 5000  # Next 5000
npx tsx scripts/importNews.ts 5000 10000 # And so on...
```

## Troubleshooting

### MongoDB Connection Error
```
Error: connect ECONNREFUSED
```
Solution: Start MongoDB or use MongoDB Atlas cloud

### CSV Not Found
```
Error: ENOENT: no such file or directory
```
Solution: Ensure `d:\Tong_Hop_Tin_Tuc_Final.csv` exists

### API Key Error
```
Error: API_KEY not found
```
Solution: Add `API_KEY=sk-...` to `.env` file

### Timeout During Enrichment
```
Error: Request timeout after 30s
```
Solution: Reduce concurrency in importNews.ts (change 3 to 2)
